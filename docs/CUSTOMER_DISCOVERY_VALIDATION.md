# Customer Discovery Validation

18startup trait framework — reference for thesis scoring methodology.

## Traits to validate

1. **Hair on fire** — buyer actively seeking relief, not curious
2. **Budget exists** — already paying for workarounds
3. **Accessible** — you can reach 10 buyers in 2 weeks
4. **Urgent** — problem costs real time/money weekly
5. **Specific** — concrete JTBD, not "better hiring"

## Mapping to scorecard

| Trait | Scorecard fields |
|-------|------------------|
| Hair on fire | urgency ≥ 4, pain_real = Y, pain_frequency = weekly |
| Budget exists | already_paying = Y |
| Accessible | persona_fit = buyer/champion |
| Urgent | pain_expensive = Y |
| Specific | rationale cites concrete instance |
